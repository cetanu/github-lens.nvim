# Contributing

Use Conventional Commits:

```text
<type>(optional scope): <description>
```

Common types are `feat`, `fix`, `docs`, `test`, `ci`, and `chore`. Use `!` or
a `BREAKING CHANGE:` footer for incompatible changes.

Release Please uses these commits to update the changelog and open release
PRs. Merging a release PR creates the version tag and GitHub release.
