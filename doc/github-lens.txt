1. Overview                                                   *github-lens-intro*

github-lens.nvim finds the pull request for the current Git branch. It shows
unresolved review comments in buffers or quickfix, and failed or pending
checks in a status window.

=============================================================================
2. Requirements                                        *github-lens-requirements*

- Neovim >= 0.10
- `git`
- Authenticated `gh` (`gh auth status`)

=============================================================================
3. Commands                                                 *github-lens-commands*

:GitHubLens [subcommand]                                      *:GitHubLens*
    Refresh data and open the status window. With a subcommand:
    - refresh  Refresh pull request comments and checks.
    - status   Toggle the status window.
    - reply    Open a reply buffer for the unresolved comment at the cursor.
    - resolve  Resolve the unresolved comment thread at the cursor.
    - quickfix Open unresolved comments in quickfix.
    - clear    Clear comments and close the status window.

=============================================================================
4. Configuration                                              *github-lens-config*

>lua
    require("github-lens").setup({
      virtual_lines = true,
      comment_hl = "DiagnosticSignInfo",
      comment_width = 80,
      comment_preview_lines = 3,
      symbols = {
        pass = "✔",
        fail = "✖",
        pending = "●",
        cancelled = "⊘",
        skipped = "⊘",
        action_required = "◆",
        comment_prefix = "│ ",
      },
      window = {
        position = "bottom", -- "bottom" split or "float" centered modal
        height_ratio = 0.3,
        width_ratio = 0.7,
        border = "single",
      },
      checks = {
        show_success = false,
      },
    })
<

=============================================================================
5. Lua API                                                       *github-lens-api*

require("github-lens").setup(opts)                         *github-lens.setup()*
    Set plugin options.

    comment_width controls the maximum display width of virtual comment lines
    (default: 80). comment_preview_lines controls how many virtual lines are
    shown before a long comment is summarized (default: 3). Whitespace-only
    body lines are omitted from the virtual preview. The status window
    displays the full comment detail.

require("github-lens").refresh()                         *github-lens.refresh()*
    Refresh pull request comments and checks.

require("github-lens").show_checks()                 *github-lens.show_checks()*
    Toggle the status window.

require("github-lens").status()                           *github-lens.status()*
    Alias for `show_checks()`.

require("github-lens").clear()                             *github-lens.clear()*
    Clear comments and close the status window.

require("github-lens").quickfix()                       *github-lens.quickfix()*
    Open unresolved comments in quickfix.

=============================================================================
6. Keymaps                                                   *github-lens-keymaps*

In the status window:
These controls are fixed and are not configurable.
- <CR>       Jump to comment / open URL / toggle fold.
- <Tab>      Toggle fold for current section or file.
- y          Yank URL (or comment location) to clipboard.
- s          Toggle showing passed CI checks.
- r          Refresh comments and checks; open a reply buffer on a comment row.
- x          Resolve the selected comment thread (from the status window).
- ] / [      Jump to next / previous actionable item.
- qf         Send unresolved comments to quickfix.
- ?          Toggle help window.
- q or <Esc> Close the window.
